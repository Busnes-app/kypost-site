# KyPost website

## Purpose

Own the public KyPost marketing pages, privacy notice and generated reference pages.

## Ownership

- `index.html`, `privacy.html`, `css/` and `assets/` own the marketing site.
- `architecture/` is generated by KyData; `docs/src/` and `docs/theme/` produce `docs/book/`. Regeneration commands are in `README.md`.
- `tests/test_site.py` and `.github/workflows/site.yml` check marketing-page references. They do not recursively validate generated content or replace browser checks.
- `README.md`, `CONTRIBUTING.md`, `SECURITY.md`, `LICENSE.txt` and `CHANGELOG.md` own usage, contribution, private reporting, licensing and notable source revisions.

## Local Contracts

- Keep this a static site; shipped HTML, CSS and scripts need no build to serve.
- Source product and security claims from the maintained product repositories.
- Edit generated documentation/map sources and regenerate; preserve generated output conventions in the README.
- Identify deployed source by full Git commit SHA and record notable user-visible/security changes in `CHANGELOG.md`.

## Work Guidance

- Add automated regression checks with major new functionality.
- Keep checks dependency-free and offline; run external-link checks separately when a destination changes.

## Verification

- Run `python3 -m unittest discover -s tests -v`.
- Inspect changed pages in a browser at desktop/mobile widths, including keyboard navigation. Run the applicable documented generator when changing generated content.

## Child DOX Index

None. The root owns the domains listed above.
